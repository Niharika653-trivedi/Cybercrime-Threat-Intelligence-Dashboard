# Cybercrime Threat Intelligence Analytics Dashboard

## Project Overview
This project analyzes cybercrime and threat intelligence data using Tableau. It presents data through visualizations and an interactive dashboard to help users understand cybercrime patterns and trends.

## Objectives
- Analyze the cybercrime and threat intelligence dataset.
- Identify important patterns and trends in cybercrime.
- Create worksheets using Tableau.
- Develop an interactive dashboard for data visualization.
- Present analytical insights in an easy-to-understand format.

## Tools and Technologies
- **Tableau:** Data visualization and dashboard creation.
- **CSV:** Dataset used for analysis.
- **GitHub:** Project hosting and version control.

## Dataset
**Dataset Name:** Cybercrime_Threat_Intelligence_Sample_Dataset.csv

The dataset is used to create Tableau visualizations and analyze cybercrime and threat intelligence information.

## Project Structure
- `Dataset/` – Contains the CSV dataset.
- `Tableau/` – Contains the Tableau workbook.
- `Screenshots/` – Contains dashboard and worksheet screenshots.
- `README.md` – Contains project documentation.
